Run all commands from inside this folder.

Setup (Windows PowerShell)
python -m venv .venv
.\.venv\Scripts\Activate.ps1
For an NVIDIA GPU, install the CUDA build of PyTorch first (skip the next line on a CPU-only machine):
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu130
pip install -r requirements.txt

The datasets are not included. CIFAR-10 and Tiny ImageNet are downloaded to ./data on the first run.
All runs use seed 42 unless --seed is given. Rows with "Data Augmentation: None" use --no-augment,
because train.py turns augmentation on by default.
--history-file saves the per-epoch numbers that the report tables and the ablation plot are built from.

Parameter check
python -m models.lenet
python -m models.lenet_modern
python -m models.alexnet

In-lab runs (these made checkpoints/lenet_baseline.pth, checkpoints/lenet_modern.pth and their plots;
they were run before the augmentation was implemented, so they need --no-augment to reproduce now)
python train.py --model lenet --dataset cifar10 --epochs 5 --no-augment --save-model checkpoints/lenet_baseline.pth --plot-file plots/loss_lenet.png --history-file history/cifar10/lenet.json
python train.py --model lenet_modern --dataset cifar10 --epochs 5 --no-augment --save-model checkpoints/lenet_modern.pth --plot-file plots/loss_lenet_modern.png --history-file history/cifar10/lenet_modern.json

python train.py --model alexnet --norm lrn --dataset cifar10 --epochs 10 --no-augment --save-model checkpoints/alexnet_lrn.pth --plot-file plots/loss_alexnet_lrn.png --history-file history/cifar10/alexnet_lrn.json
python train.py --model alexnet --norm bn --dataset cifar10 --epochs 10 --no-augment --save-model checkpoints/alexnet_bn.pth --plot-file plots/loss_alexnet_bn.png --history-file history/cifar10/alexnet_bn.json

Notes
- Only lenet_baseline.pth, lenet_modern.pth and alexnet_bn.pth are in the zip, to keep it small.
  The other checkpoints are made by the commands above.
- The terminal output of every run is in logs/. The other logs/evaluate_*.log files were made with evaluate.py
  in the same way, on checkpoints that are not in the zip.
- The LeNet table numbers come from re-running the in-lab commands without --save-model and --plot-file.
  They are identical to the in-lab checkpoints (54.91% and 65.40% with evaluate.py).
